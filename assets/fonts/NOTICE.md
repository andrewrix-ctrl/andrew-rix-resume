# Bundled fonts

Both families are redistributed here under the SIL Open Font License 1.1, which
permits bundling and self-hosting. The full licence text and copyright notices
are carried in each `.woff2` file's metadata and published by the upstream
projects:

- **Bricolage Grotesque** — Atelier Triay · https://github.com/ateliertriay/bricolage
- **IBM Plex Sans** — IBM · https://github.com/IBM/plex

Files are the `latin` and `latin-ext` variable subsets as served by Google
Fonts. Browsers fetch only the subset a page actually needs, so the two
`latin-ext` files usually go unrequested.
